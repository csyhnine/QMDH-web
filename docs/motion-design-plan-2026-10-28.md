## A：管理浮层轻入场

建议仅修改 `management.css`，不改 TSX 和业务逻辑。
所有浮层只做入场 opacity，不做退出动画、位移或缩放。

### A1 快捷卡片

- 挂点：`QuickWorkActions.tsx` 14–54 行；CSS 约 2117–2118 行。
- 触发：用户点击工作柱或工作条，现有快捷卡片显示。
- 样式：`.mp-quick-panel` 从透明到不透明，120ms ease-out。
- `.mp-quick-layer` 可用 100ms 淡入，保持原有遮罩强度。
- 卡片位置、边缘避让、命中范围和定位测量保持不变。
- 完成态：保持静止，不常驻呼吸；关闭立即执行。
- 失败态：保留现有输入和错误信息，不以红色抖动表达错误。
- 减动：卡片和层直接显示最终 opacity，无动画。

### A2 日期日历

- 挂点：`PlanningDate.tsx` 20–35、51 行；CSS 约 1932–1933 行。
- 触发：现有 `.mp-calendar:popover-open` 打开。
- 样式：opacity 淡入 100–120ms，不动尺寸和 transform。
- top-layer 提升绘制层，不会自动把元素搬到 body。
- 普通管理页日历仍在原 DOM；快捷卡片里的日历会随 portal 位于 body。
- 完成态：选日期和键盘操作立即可用；hidePopover 立即执行。
- 失败态：日期限制、无效日期和既有错误表达不改变。
- 减动：直接覆盖 `.mp-calendar`，不能只依赖管理页后代选择器。

### A3 确认框

- 挂点：`confirmPlanning.ts` 23、47、78 行；CSS 约 2107–2108 行。
- 触发：现有站内确认框打开。
- 样式：`.mp-confirm-dialog` 与 `::backdrop` 淡入 120–140ms。
- 不改居中 transform，不让动画覆盖现有定位。
- 完成态：确认、取消、Escape 均立即响应和关闭。
- 失败态：沿用当前调用方错误处理，不因动效吞掉异常。
- 减动：dialog 与 backdrop 都直接显示最终状态。
- 保留 Promise 队列、默认取消焦点、Tab 循环、焦点恢复与 busy 锁。

A 的错误提示淡入可留到后批；错误区高度变化须先核验视口边缘定位。

## B：生成状态与新结果

- 实际入口：`GeneratePage` → `features/studio/GenerateStudioShell.tsx`。
- 结果挂点：`StudioFeedCardResult.tsx`、`StudioHistoryFeedItem.tsx`。
- 状态类型参考 `studioHistoryFeedTypes.ts`；样式在 `styles.css`。
- 触发：当前会话已观察 pending/running，随后真正出现可展示素材。
- 以 `taskId + assetId` 在会话内去重；不能仅给 completed 状态加 class。
- 初次历史加载、分页、轮询重复响应和路由重挂载不重播。
- 等媒体 load/decode 后实际可显示再淡入；加载失败走错误态，缓存就绪也只播一次。
- 去重保存在路由重挂载之外，按登录与作用域隔离并有界，不写业务快照；无需新增复杂框架。
- 样式：图片内部 opacity 180–220ms；优先不加位移。
- 4px 内部位移仅作后续可选，不作为首版要求。
- 预留稳定结果尺寸，禁止用动画掩盖布局跳动。
- 生成状态复用既有进度能力，不加假进度或倒计时。
- 完成态：结果最终清晰可操作，不等待动画结束才能下载或打开。
- 失败态：保留错误、重试和取消能力；不能播放成功反馈。
- 减动：新结果立即显示，真实状态文字与进度仍保留。

## C：导航切换

- 挂点：`features/studio/StudioSectionTabs.tsx` 与 `studioSectionTabs.css`。
- 触发：链接 hover、focus-visible 或 `aria-current` 改变。
- 样式：链接自身 background、color、box-shadow 120–160ms。
- 静态白底和阴影已经存在，只补状态之间的轻过渡。
- 固定 56px 导航布局保持不变，不加共享滑块或整路由滑入。
- 完成态：当前页标识清晰，导航立即生效。
- 失败态：路由错误沿用原表达，不用动效伪装成功跳转。
- 减动：取消过渡，保留清晰选中态和焦点态。

## D：Canvas 内部反馈

- 入口：`features/canvas/CanvasWorkspace.tsx`。
- 节点：`GenerateNode.tsx`、`NoteNode.tsx`、`GroupNode.tsx`。
- 生成状态参考 `CanvasNodeTaskProgress.tsx`、`useCanvasNodeGenerate.ts`。
- 用户主动新建节点：内部描边一次，约 240ms，不移动节点。
- running 转完成且有结果：内层淡入 180ms，边框反馈约 300ms。
- 新建临时 UI 标记不能写入 nodes 持久化 data 或快照。
- 历史恢复、撤销恢复不算新建，不播放新建反馈。
- 完成态：节点停在原位，拖动、选择、连线立即可用。
- 失败态：沿用错误与重试，不播放完成边框。
- 减动：取消淡入及描边动画，保留稳定状态表达。
- 禁止在 ReactFlow 节点外壳、viewport、连线添加 transition/transform 动效。
- 禁止自动移动视口来展示新节点或结果。
