# 人员排期缩放、双击新增与并行泳道

人员排期表内按住 Ctrl 滚轮可调整一页显示的日期数。向下滚显示更多日期，向上滚放大日期；提供同等缩放按钮和重置。按鼠标指向的日期锚定新范围，翻页按当前可见天数前后移动；选择周/月/季度/年或重置可回到自然周期。缩放只改变视图，不修改任务日期或保存业务数据。普通滚轮仍滚动，表外 Ctrl 滚轮不拦截。

日期格不再显示加号。单击只聚焦，双击打开极简新增工作卡片，预填所在人员、日期，保存后成为独立泳道；键盘聚焦空格后按 Enter 或空格也可新增。继续复用原有工作编辑和保存流程，没有恢复已移除的人员侧栏或安排工作入口。

人员列保持约 60px 最小宽度，并行工作共享列内空间并自动压窄。10 项并行工作不会撑宽该人员列，也不重叠；两侧保留空白新增位置。过细泳道隐藏难以辨认的竖排字，悬停可读完整项目/工作名，点击仍打开快捷操作，顶部拖动区域保留。筛选外工作仍参与负荷提示，暂停与临时支援语义保持。

修正日期列原有内边距导致月/季度日期行被撑高的问题，确保底表、工作柱、指针命中使用同一日高。缩放最少显示 3 天，最大按视口及 18px 最小行高约束，避免密集日期标签重叠；窄屏仍允许横向滚动人员列。
