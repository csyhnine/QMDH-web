# 公司项目管理

入口 `/management/projects`，仅当前公司管理层账号可见。网站管理员与运营账号不会自动获得台账权限；账号页可以独立维护公司管理层、所属单位与职务。撤销后旧会话立即失去后端访问权限。

年度台账包含序号、项目名称；项目统筹、设计经理、设计副经理、商务经理、驻场设计、参与人员；下周主要工作内容/使用人员、阶段工作、完成时间节点、等级、紧急程度；工程投资、设计费、合同签订、设计回款、请款中（已开发票）；项目模式、来源、类型、阶段和备注。金额均万元、两位小数，空白表示未知，0 表示确认零金额。导出 CSV 保留当前过滤结果。

先在人员管理添加员工，再新建项目并选择分工，每项阶段填写名称、开始/结束日期、人员、分配比例和进度。里程碑为同日。甘特图支持项目/人员分组、人员/项目名过滤、两周/30/90 天、点击条目编辑。红底表示同一人同一天分配合计超过 100%；按日历日计算、不扣周末，不表示真实工时或绩效结论。跨年度阶段跟随项目所属年度查看，未排期项目不会自动生成假日期。

多人保存同一个项目时，以版本原子比较，旧页面显示冲突并保留输入。请先自行保留输入，再关闭编辑、刷新后重新应用。项目可归档/恢复；人员可停用/启用；修改保存保留项目版本快照，受限接口 GET /management/projects/{id}/revisions 可读最近 50 次版本，尚无版本对比界面。

真实员工及授权是生产业务数据，不在代码中预置。初始台账编制、资料日期由用户提供；项目明细尚未提供，因此不填示例项目。迁移 a16c9e74b821 是追加字段与表；回滚程序不降级删除数据。
