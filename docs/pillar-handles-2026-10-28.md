# 泳道底端边界修复与整项移动分离

复现用户反馈：旧usePillarResize把指针改期夹在当前周/月日期内，周日再向后拖仍得到原周日；日期在视图外时不渲染该端手柄，底端数量为0；原整项手柄和上端仅隔2px。新增密集单日命中检查还发现主体按钮的18px顶部内边距会把14px短柱撑出格子，视觉底边和实际手柄不一致。

移除视窗日期夹取，保留staffPlanning的另一端固定、最短一天和最长约十年限制。上下手柄始终保留；视图外端点用虚线表示并在标题/实时浮签展示真实日期，按相对位移调整真实起止，不在按下/单击时突然截短回视窗内。修正主体padding造成的高度溢出，端点最多14px并随短柱缩小，中央至少留4px用于点击快捷卡片，密集短柱隐藏难辨文字。未自动改动项目交付日、其他工作或参与人员。

移除柱体内整项平移手柄。普通状态只允许端点改期/柱体划选，不可原生拖动整项。人员快捷卡片显式选择“整项移动”后，只有该工作高亮且柱体可拖；提示起止一起移动，可拖至目标日期/人员，松手/取消/Esc退出移动模式。此模式隐藏选中工作的端点，操作不会混用。项目计划DHTMLX自身移动/拉伸保持。
