# 固定生成页签与后台导航归组

生成工作台和无限画布使用相同的 56px 导航行，生成页签移到项目侧栏与内容区之上的独立行，内容滚动不带走页签。桌面、390px 手机和画布视口都保留可用空间。窄屏画布将项目库/节点配置放在画布下方滚动，工具栏提示不再挤占画布。

后台原 11 个一级入口收为五组，只展示当前组的子页面，去掉路由内重复的数据/模板标签行。各页地址、路由鉴权和模块权限保留，运营角色仍只有原有六项权限；公司项目管理独立入口仍按公司管理授权显示。后台子导航共用吸顶行，未处理反馈提示保留。

| 分组 | 子页面 |
| --- | --- |
| 看板 | 运营看板 |
| 数据 | 生成分析、Chat 体验、日志、图纸解析 |
| 内容 | 灵感、反馈、公告、工具导航 |
| 创作 | 模型、生成模板、画布模板、助手能力 |
| 系统 | 账号、设置 |

验证：5 项导航测试和 20 项管理回归通过，20 个目标文件严格类型诊断零新增，Vite 构建通过（保留既有大块提示）。5 个完整浏览器场景加载实际 AppRouter、生成控制器、生成页/画布和后台壳：桌面生成/画布页签坐标与滚动、后台分组/单导航行/吸顶、运营权限与禁用地址跳转、手机生成/画布可用区域、手机后台长内容滚动。API 为合成数据并阻断外部访问，未执行写请求或真实生成。

当前为已验证候选，尚未发布。只读线上预检时磁盘约 7.900 GiB，低于交接规定的 8 GiB 门槛，因此没有开始替换服务。已向用户申请仅删除一条约 514 MB、可回收且未被镜像共享的旧构建缓存后发布，等待用户选择；没有自行清理缓存、正式备份、镜像或工作流。
