# 工作卡片保存关闭与快捷删除泳道

工作卡片页头改成相邻的“不保存关闭”和蓝色“保存关闭”，去掉分散的关闭/保存卡片按钮。明确选择不保存直接关闭，不再二次确认。点击卡片外遮罩空白会提交同一表单并在成功后关闭，卡片内部空白和自定义日历操作不触发保存。新增与已有工作编辑共用此行为，原部分日期改派仍走既有原子接口。

外部点击使用 requestSubmit，保留必填/日期限制；空白名称还会进行 trim 校验。校验不通过、保存失败或版本冲突时保留卡片与输入。保存中锁定按钮及关闭，重复点击遮罩不会重复提交；不穿透到背景导航或排期表。

人员竖柱与项目甘特共用的快捷卡片新增“删除泳道”（交付节点显示“删除交付节点”）。通过站内中央确认框明确说明删除整项工作及所有参与人员的泳道，取消不写入。确认后复用当前项目版本保存并仅移除对应 stage，其他工作、项目与人员资料保留；失败保留快捷卡片和当前选项，可重试。归档/禁用与忙碌状态继续限制操作。此为整项工作删除，单人部分时段仍使用原暂停/支援功能。
